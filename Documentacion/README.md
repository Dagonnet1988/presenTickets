1. [**Introducción**](1_introduccion.md) - Descripción general del sistema, sus características y tecnologías.

## Uso

Esta documentación está diseñada para:

1. **Desarrolladores** - Proporcionar información técnica necesaria para entender, instalar, configurar y mantener el sistema.
2. **Administradores** - Ofrecer guías de instalación y configuración.
3. **Stakeholders** - Clarificar aspectos legales y de propiedad intelectual del software.
